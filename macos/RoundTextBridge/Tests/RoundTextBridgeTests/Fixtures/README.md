Source: https://github.com/scikit-image/scikit-image/blob/v0.25.2/skimage/data/astronaut.png
The scikit-image data documentation identifies it as a NASA image released into the public domain:
https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.astronaut

Used only to verify local face cropping, orientation and landmark alignment; it is not a user avatar.
